# Local-engine extras: install on top of requirements.txt when you want to run
# STT and TTS on this machine instead of routing to Groq.
#
# CUDA note (RTX 5070 / Blackwell, sm_120): PyTorch cu121 wheels ship NO kernels
# for sm_120 and fail at the first CUDA op with
#   "no kernel image is available for execution on the device".
# Install torch from the cu126 index (or newer) FIRST, then this file:
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
#
# Apple Silicon and CPU-only machines need nothing extra — faster-whisper and
# kokoro-onnx below both run on CPU, and Ollama drives the GPU itself.

-r requirements.txt

# faster-whisper 1.1.1 imports `requests` at module load but does not declare
# it as a dependency — without this line the import fails with ModuleNotFoundError.
requests==2.32.3
kokoro-onnx==0.4.9

# GPU ONNX runtime. Uncomment BOTH lines (and comment out `onnxruntime` in
# requirements.txt — the two ship the same module and cannot coexist) on an
# NVIDIA machine. Measured on an RTX 5070: TTS 901 ms -> 203 ms, mean end-to-end
# 1163 ms -> 450 ms, which is what takes this project under its 800 ms target.
# See docs/decisions.md -> D-03.
#
# Costs, both measured, both real: ~2.2 GB of nvidia-* wheels on disk, and the
# CUDA context inside an 8 GB VRAM budget already holding Ollama and Whisper.
