Clone on GitHub Setup & docs

This Hugging Face Space is a static project page. Free accounts cannot run Docker or Gradio Spaces, so the live microphone / WebSocket agent is not hosted here. Run it locally with the commands below. A Groq-backed Docker Space needs Hugging Face PRO.

Run local

git clone https://github.com/AKASH-CODZ/Voice-Ai.git
cd Voice-Ai
cp .env.example .env
make setup && make models
make backend    # :8000
make frontend   # :3000

Python 3.11 or 3.12 only. Optional GROQ_API_KEY in .env for cloud fallback. Never commit that file.

What it is

Native WebSocket

PCM16 in at 16 kHz, out at 24 kHz. Silero VAD for turn-taking. No LiveKit in the default path.

One clone, one machine

The probe picks local vs cloud from the computer you start. M4 and RTX 5070 are independent hosts, not a pair.

Three modes

Casual, tutor, silent mock-interview — each prompt is runtime source in the repo, not a docs leftover.
